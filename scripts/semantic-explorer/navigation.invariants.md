# Semantic Navigation Invariants

The Semantic Explorer lets users browse claims without following the codebase layout.

## §1 Exploration lenses

### §1.1 Users can explore semantics by subject, claim kind, cross-cutting status, and text

The interface includes every subject and lets users filter claims by invariant or scenario kind, local or cross-cutting status, and text found in subject names, claim identifiers, titles, or statements. After a user selects a subject, the interface displays all of its claims and proofs. After the user selects a claim, the interface displays its complete statement, proof links, and source location.
