# Review

Read the [shared guidance](../semantic-claims-claim/GUIDE.md) and the references relevant to the request.

Inspect the requested subject or diff for warranted behavior without claims, redundant or unwarranted claims, incorrect claim kinds or scope, weak or incorrectly linked proofs, and implementation behavior that contradicts the claims. Check assertions and relevant event orders as well as structural checker results.

Complete a review with actionable findings, their locations, and observable consequences, ordered by importance. State any limits on verification. If there are no findings, say so. Preserve files unless the user also requests fixes.
