# Claim

Read the [shared guidance](GUIDE.md) and the references relevant to the request.

Name the subject, establish the intended observable behavior, and decide which behavior warrants a claim. Write or revise the claim documents using the method's invariant, scenario, and cross-cutting conventions.

Complete a claim-only request with the claim documents and their proof obligations. Report unresolved intent before editing the affected claims. Leave proofs and implementation for their requested stages; do not add placeholder tests to satisfy the structural checker.
