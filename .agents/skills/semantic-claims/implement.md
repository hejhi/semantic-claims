# Implement

Start from the intended behavior and applicable claims. If the request authorizes new or changed behavior, update the warranted claims first. Write or repair proofs before changing the implementation; when behavior is missing or wrong, confirm that the proofs fail for that behavior.

Make the implementation satisfy the claims. Complete the requested work through structural checks, executable proofs, relevant project checks, and fixes for failures caused by the change. Review the claims, proofs, and implementation together before reporting completion.
