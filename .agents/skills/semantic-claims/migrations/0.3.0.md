# Migration to 0.3.0

Release 0.3.0 changes [Claims specify meaning](../SKILL.md#claims-specify-meaning) and [Claim kinds](../SKILL.md#claim-kinds). The 0.3.0 checker accepts every claim document that the 0.2.0 checker accepts.

## Procedure

Apply the [review checks](../SKILL.md#review-checks) in order to each claim in the project, and fix each finding. Propose each claim deletion to the user before applying it, and decide every other semantic question under [Who decides semantics](../SKILL.md#who-decides-semantics).

Report each claim deleted, moved, split, or rewritten, and each question asked.
