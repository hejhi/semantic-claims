# Migration to 0.2.0

Release 0.2.0 changes [Claims specify meaning](../SKILL.md#claims-specify-meaning), [warrant](../SKILL.md#choosing-when-and-how-to-write-semantic-claims), [Claim kinds](../SKILL.md#claim-kinds), [Cross-cutting claims](../SKILL.md#cross-cutting-claims), and [Document structure](../SKILL.md#document-structure), and its checker enforces the new statement form. Claim documents written for 0.1.x fail the 0.2.0 checker until they are migrated.

## Procedure

Apply the [review checks](../SKILL.md#review-checks) in order to each claim in the project, and fix each finding. Propose to the user, before applying it, each claim deletion and each new system name other than one made by removing a kind word, such as "Invariants", from a document's heading, and decide every other semantic question under [Who decides semantics](../SKILL.md#who-decides-semantics).

Report each claim deleted, moved, split, or rewritten, and each question asked.
