# Prove

Read the [shared guidance](../semantic-claims-claim/GUIDE.md) and the references relevant to the request.

Use accepted claims to write or repair their paired proof files. Test the observable behavior at the subject's supported boundary, including relevant conditions and event orders. Follow the project's exact proof-linking conventions.

Run the structural checker and executable proofs. Complete a proof-only request with runnable proofs and an explanation of their results. A failure caused by missing or incorrect behavior is an expected result at this stage; fix broken test setup and distinguish it from a behavior failure. Preserve accepted semantics and leave implementation changes for an implementation request.
